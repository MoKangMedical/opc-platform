# OPC能力搭建学院 — 完整实施计划

## 目标
在 OPC Platform (opcplatform.cn) 下新建独立课程体系 **「OPC能力搭建学院」**，对标康波研究院的设计品质，包含：
- 10门核心课程，每篇约5000字
- 每课配备TTS音频（Edge TTS, zh-CN-YunxiNeural）
- 课程主页 + 单课页面
- 5轮QC迭代，逐步上新功能
- GitHub Pages 自动部署

## 技术栈
- 纯静态 HTML/CSS/JS（与 OPC Platform 一致）
- 设计系统：深空暗色 + 金色(#e2b64f)主题（与康波研究院统一）
- 字体：Noto Serif SC（标题）+ Inter（正文）
- TTS：Edge TTS Python 脚本
- 部署：GitHub Pages → opcplatform.cn/opc-academy/ 或独立子路径
